# 📞 Telegram Phone Bot

Телефони телеграмӣ — занг, СМС, рақамҳои сохтагӣ. Бот барои Telegram, ки дар дохили он рақам месозӣ, занг мезанӣ ва СМС менависӣ.

## Имкониятҳо

- **📱 Сохтани рақам** — рақами 8-рақамаи дилхоҳатонро созед
- **📞 Занг задан** — ба рақами дигар корбарон занг бизанед
- **✉️ СМС фиристодан** — паём ба рақами дигар корбарон нависед
- **🔗 Пайваст шудан бо бегонагон** — суҳбати тасодуфӣ бо корбари дигар
- **👑 Панели админ** — ирсоли паём ба ҳама, дидани одамон, ирсоли СМС аз номи админ
- **💾 Нигоҳдории доимӣ** — ҳама маълумот дар SQLite нигоҳ дошта мешавад

## Насб

```bash
pip install -r requirements.txt
```

## Танзим

Дар файли `bot.py` `BOT_TOKEN` ва `ADMIN_ID`-ро иваз кунет.

## Иҷро

```bash
python bot.py
```

## Deploy 24/7 (Render.com — ройгон)

1. Ба https://render.com равед ва бо GitHub ворид шавед
2. **"New +"** → **"Background Worker"**
3. Репо интихоб кунед: `strax674/telegram-phone-bot`
4. Render автоматӣ аз `render.yaml` танзим мегирад
5. **Create Background Worker** пахш кунед

Бот 24/7 кор мекунад ва ҳар дафъаи код дар GitHub иваз шавад, худ аз худ нав мешавад.

## Deploy 24/7 (Railway.app)

1. Ба https://railway.app равед
2. **"New Project"** → **"Deploy from GitHub repo"**
3. `telegram-phone-bot`-ро интихоб кунед
4. Deploy автоматӣ
