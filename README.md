# 📞 Telegram Phone Bot

Телефони телеграмӣ — занг, СМС, рақамҳои сохтагӣ. Бот барои Telegram, ки дар дохили он рақам месозӣ, занг мезанӣ ва СМС менависӣ.

## Имкониятҳо

- **📱 Сохтани рақам** — рақами 8-рақамаи дилхоҳатонро созед
- **📞 Занг задан** — ба рақами дигар корбарон занг бизанед
- **✉️ СМС фиристодан** — паём ба рақами дигар корбарон нависед
- **🔗 Пайваст шудан бо бегонагон** — суҳбати тасодуфӣ бо корбари дигар
- **👑 Панели админ** — ирсоли паём ба ҳама, дидани одамон, ирсоли СМС аз номи админ

## Насб

```bash
pip install -r requirements.txt
```

## Танзим

Дар файли `bot.py` `BOT_TOKEN` ва `ADMIN_ID`-ро иваз кунет.

## Иҷро

```bash
python bot.py
```
